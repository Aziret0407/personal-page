
Final Project

## Project Description

This project is a Kyrgyzstan-themed news portal website created as the final project for COM 360.  
The assignment requires **one HTML file** and **two different CSS versions** of the same website.

The website includes all major content blocks required in the project:
- header and logo
- search bar
- navigation menu
- hero section
- news section
- info section
- video section
- portal section
- cinema section
- chronicle section
- extra/ad blocks
- images and text content

## Files Included

- `index.html` — the main single-page HTML file
- `style.css` — the first version of the website in a classic portal layout
- `style2.css` — the second version with a modern redesigned responsive style
- `assets/` — images and graphic files used in the project

## Requirements Completed

This project follows the main final project requirements:
- one single `index.html`
- two CSS versions using the same HTML structure
- no changes to HTML for the redesigned version except switching the CSS file
- responsive layout for desktop and mobile
- under `500px`, all content stacks into one column
- images and text remain visible on different screen sizes
- CSS uses Grid, Flexbox, percentages, and media queries
- no large spacing or position values greater than `50px` for layout hacks

## Responsive Design

The website was designed to work on:
- desktop
- tablet
- mobile screens

Special attention was given to smaller screen sizes such as:
- `1000px`
- `768px`
- `500px`
- `390px`
